# 우애영 MVP Brief

## 문제

여러 제품을 급여하는 보호자는 실제 하루 급여량 기준의 총 영양소와 중복 가능성을 한눈에 확인하기 어렵다.

## 사용자

사료 외 간식·영양제를 2개 이상 함께 급여하는 성견 보호자.

## 핵심 시나리오

제품과 급여량을 입력하면 영양소 총량과 제품별 기여도가 나타나고, 제품 하나를 끄면 변경 결과를 즉시 비교한다.

## MVP

- 검수 제품 선택과 급여량 입력
- 영양소 공통 단위 환산·합산
- 중복·기준 초과 가능·정보 부족 상태
- 제품별 기여도 그래프와 제품 제외 시뮬레이션

## 제외

질병 진단·처방, 약물 상호작용, 실시간 최저가, OCR 자동 확정, 실제 영양 기준으로서의 사용.

## 성공 지표

단위 변환 테스트 100%, 경고 근거 표시 100%, 누락 라벨 정보 부족 처리 100%.
